# C++ Unit Tests

This directory is reserved for C++ unit tests for the QD library integration and other C++ components.

## Purpose
- Test C++ implementations of high-precision arithmetic
- Verify QD library integration
- Test performance-critical C++ code paths

## Status
Currently, C++ tests are performed via compiled executables in the project root directory.
This directory structure is maintained for future C++ test framework integration (e.g., Google Test).
