# WP3-UP-CAND-v1 Search Boundary

This package evaluates all monomials through total degree three in the 14
dimensionless canonical variables of `WP2-UP-v1`.  Known physical energy and
angular-momentum controls are appended and projected out before ranking.
Multiple KS gauges are included so a surviving scalar must also remain stable
across the sampled gauge orbit.

A null result excludes only this finite polynomial grammar on the frozen
development/calibration corpus and thresholds.  A numerical mode is not a
first integral.  It can only trigger a separately frozen candidate-specific
qualification; the sealed publication reserve must remain unopened until then.
