# WP3-MULTI-CAND-v2 Observable Known Quotient

This successor preserves the original WP3 v2 campaign and corrects only the
known-module quotient order. The active feature matrix is first mapped into
observable function space. The complete value-nuisance representation kernel
is then separated, and the qualified `L^2` response class is removed in the
observable value metric before the generalized Lie/value spectrum is fitted.

Development, calibration, and the independent 192-state challenge corpus are
searched with NumPy SVD and both SciPy LAPACK drivers. A bounded-null result is
authorized only if every backend-guarded lower bound exceeds the frozen
`1e-10` threshold. Candidate coefficients, if any, remain uninterpretable
until another candidate-specific specification is locked. The 24-case
publication reserve is never opened by this campaign.
