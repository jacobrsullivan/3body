# WP3-MULTI-CAND-v1 Search Boundary

This package implements the finite-library search frozen in
`validation-external/wp3-multi-candidate-v1/search_spec.json`.

The library uses one shared coefficient vector in all three WP2-MULTIQ-v1
charts. It contains every combined-degree-three-or-less monomial with at least
one of the 16 non-time canonical two-spinor variables and optional fixed-energy
or symmetric-mass factors. Admissible directions must satisfy the physical
Lie, two gauge-generator, and chart-overlap constraints.

The package is search machinery, not evidence of an additional first integral.
It excludes chart-asymmetric, higher-degree, nonpolynomial, nonzero-Xi, and
triple-collision claims. Candidate interpretation remains prohibited until the
campaign publication gate and any triggered candidate-specific qualification
have passed.
