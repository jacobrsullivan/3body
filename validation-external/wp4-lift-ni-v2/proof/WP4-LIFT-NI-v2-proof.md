## T1 Single KS Reduction

For one spinor `q=(q1,q2,q3,q4)`, define

```text
kappa(q) = (
  2*(q1*q3+q2*q4),
  2*(q1*q4-q2*q3),
  q1^2+q2^2-q3^2-q4^2
),
r = q.q,
Y(q) = (-q2,q1,-q4,q3).
```

Direct polynomial multiplication gives

```text
|kappa(q)|^2 = r^2,
Dkappa*Dkappa^T = 4*r*I3,
Dkappa^T*Dkappa = 4*r*I4 - 4*Y*Y^T,
Dkappa*Y = 0.
```

Thus `Dkappa` has rank three for `q != 0`, and its one-dimensional
configuration kernel is generated by `Y`. The cotangent action rotates both
`q` and `P`; its infinitesimal phase-space generator is `(Y(q),Y(P))`. With
the canonical symplectic form, its momentum map is

```text
Xi(q,P) = Y(q).P.
```

The physical cotangent projection is

```text
x = kappa(q),                 p = Dkappa(q)*P/(4*r).
```

Exact differentiation gives

```text
{x_i,x_j} = 0,
{x_i,p_j} = delta_ij,
{p1,p2} =  Xi*x3/(2*r^3),
{p1,p3} = -Xi*x2/(2*r^3),
{p2,p3} =  Xi*x1/(2*r^3).
```

Consequently the projected bracket is canonical on `Xi=0`. The derivative
of `(x,p)` has rank six, the derivative of `(x,p,Xi)` has rank seven, and
the common kernel on the zero-level tangent space is exactly the cotangent
circle generator. This proves the regular zero-level quotient locally. The
exact identities are checked once by the dependency-free production module
and independently by symbolic differentiation in the SymPy reference.

## T4 Sundman Transfer

Let `F` be a projectable function with no explicit `t` dependence, and write
its quotient as `F_bar(z,p_t)`. The canonical product rule gives

```text
{F_bar,K}
  = {F_bar,g*(H+p_t)}
  = g*{F_bar,H} + (H+p_t)*{F_bar,g},
```

because `{F_bar,p_t}=partial_t F_bar=0`. On `K=0`, where `p_t=-H` and
`g != 0`, this reduces to

```text
{F_bar,K}=0  if and only if  {F_bar,H}=0.
```

This is an on-shell statement. Multiplication by a nonconstant clock is not
claimed to preserve the Hamiltonian vector field away from `K=0`. The exact
checker evaluates both the full product rule off shell and its shell
specialization.

## T5 Involution Transfer

The physical shell restriction of an admissible function is

```text
f_i(z) = F_bar_i(z,-H(z)).
```

Put `b_i=partial_(p_t) F_bar_i` on the shell. Then

```text
d f_i = d_z F_bar_i - b_i*dH.
```

T4 and upstairs conservation imply `{F_bar_i,H}_z=0` on the shell. Hence

```text
{f_i,f_j}_z
 = {F_bar_i,F_bar_j}_z
   - b_j*{F_bar_i,H}_z
   - b_i*{H,F_bar_j}_z
 = 0.
```

The same calculation gives `{H,f_i}=0`. Thus possible `p_t` dependence does
not spoil conservation or involution after shell restriction.

## T6 Shell Rank Transfer

Use regular momentum-map coordinates

```text
(z,t,theta1,theta2,p_t,I1,I2),       I_a=Xi_a,
```

where the two angle-momentum pairs are canonical. Commutation with `p_t` and
the two `Xi` functions removes `dt` and `dtheta_a` components from `dF_i`.
The physical shell is

```text
S = {I1=I2=0, K=0} = {I1=I2=0, p_t=-H}.
```

At a point of `S`, write

```text
dF_i = A_i + b_i*d p_t + c_i^a*dI_a,
dK   = g*(dH+d p_t) + k^a*dI_a
```

on `K=0`. The second equation allows harmless transverse `I` derivatives;
the `(H+p_t)*dg` term vanishes on the shell.

Suppose the descended six functions lose rank at that same shell point:

```text
a*dH + sum_i lambda_i*(A_i-b_i*dH) = 0.
```

Set

```text
c = (a-sum_i lambda_i*b_i)/g.
```

Then `sum lambda_i*dF_i + c*dK - a*d p_t` has zero `z` and `p_t`
components. Add a suitable linear combination of `dI1,dI2` to cancel its
remaining `I` components. This constructs a linear dependence among

```text
dK, d p_t, dI1, dI2, dF1, ..., dF5.
```

Rank nine of the upstairs covectors at the shell point forces every
coefficient to vanish. In particular `lambda_i=0` and `a=0`. Therefore,
pointwise on `S`,

```text

```

whenever the upstairs rank is nine. The full-rank locus is open and invariant
under the `T2` action. The v2 admissibility definition requires it to be
relative dense in `S`; its quotient is therefore relative dense in
`S/T2`, and the shell graph `p_t=-H` identifies that quotient with the
physical neighborhood. This transfers dense-open rank six.

Shell-relative rank nine is essential. The exact v1 counterexample in adapted
canonical coordinates is

```text

(F1,F2,F3,F4,F5)=(p2,p3,p4,p5,I1*p6).
```

Together with `(K,p_t,I1,I2)`, this family is pairwise commuting and has rank
nine where `I1 != 0`. On `S`, `d(I1*p6)=p6*dI1` supplies no direction beyond
`dI1`, so the shell rank is eight and the projected physical rank is five.
The qualification must reject this ambient-only rank family. A separate

## T8 Spatial Variational Subquotient

```text

```

Reflection in the physical plane,

```text

```

planar translation-reduced phase space. Along a planar solution, the
linearized Hamiltonian matrix commutes with `dR`; therefore the `+1`
in-plane and `-1` vertical eigenspaces are invariant.


isotropic in the three spatial axes and has the same block property. Exact
assembly of all three pair terms verifies that the in-plane block of the
spatial variational matrix equals the independently differentiated planar
variational matrix.


## T10 Global Implication

Assume a global shell-regular physically admissible family exists on a WP2
atlas domain containing the regular lifted parabolic Lagrange neighborhood.
By definition it has the nine commuting members

```text

```

and rank nine on a relative dense-open subset of the physical shell. Restrict
it to that neighborhood. T1 through T3 project it; T4 and T5 make its shell

Therefore no such global admissible family exists. The word `global` occurs
only in this implication: a global family would have a forbidden local
restriction. The proof does not classify all trajectories and does not turn
a local variational calculation into an unqualified absence-of-integrals
claim.
