# WP3-UP-CAND-v2

This superseding campaign repeats the preregistered search on qualified
`WP2-UP-v2` while binding every spatial checkpoint file consumed by the
runner to the upstream qualification record and the pre-search lock. The
hypothesis class contains every combined-degree-three-or-less monomial with at
least one of the 14 canonical state variables and optional fixed-energy and
symmetric-mass factors. It evaluates exact Lie derivatives, removes value
identities and the represented known algebra, and tests remaining modes on
disjoint calibration data and multiple gauges.

The sealed 24-case publication reserve is commitment-only input.  This
campaign cannot execute it.  A surviving mode can only trigger a new
candidate-specific qualification lock.

```bash
./validation-external/wp3-upstairs-candidate-v2/run_search.sh build
./validation-external/wp3-upstairs-candidate-v2/run_search.sh freeze
./validation-external/wp3-upstairs-candidate-v2/run_search.sh search
./validation-external/wp3-upstairs-candidate-v2/run_search.sh report
./validation-external/wp3-upstairs-candidate-v2/run_search.sh finalize
```
