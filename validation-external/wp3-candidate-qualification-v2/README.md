# WP3 Candidate Qualification v2

This gate consumes the immutable `WP3-UP-CAND-v2` search record. It may create
a candidate-specific qualification requirement only when the frozen search is
ready and exactly one mode passed every candidate gate. A zero-candidate result
must leave the publication reserve sealed and WP4 candidate interpretation
blocked.

Run `./validation-external/wp3-candidate-qualification-v2/run_gate.sh`.
