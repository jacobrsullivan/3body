# WP4-MR-NI-v2 Qualification Boundary

This module exactly reproduces and applies the symmetric mass arithmetic used
by the two externally pinned planar three-body non-integrability analyses. It
does not rederive their normal variational equation, factorization, local
logarithmic solutions, monodromy generators, or differential Galois group.

A positive-mass result is conditional on those published analyses and concerns
complete meromorphic Liouville integrability of the planar Newtonian problem
near the parabolic Lagrange solution with fixed nonzero angular momentum. It
does not establish a spatial-system theorem, a statement restricted to the
zero-angular-momentum level, a non-meromorphic obstruction, or validation of
any WP3 candidate.

Membership in the first-variational-equation exceptional set is exact. Such a
membership reports a polynomial invariant of the linear normal variational
equation only; it is not evidence for a nonlinear additional first integral.
The incomplete legacy `src/python/validation/kovacic.py` module is outside this
implementation and qualification scope.
