# WP6-DZ-FEAS-v2 qualification boundary

This package implements the frozen finite constructive search in
`validation-external/wp6-dz-feas-v2/constructive_protocol.json`.

The model is the full positive-mass Newtonian rectilinear flow in one ordered
collision-free chamber after translation reduction. The collinear chart is a
discovery restriction, not a claim that the full planar system is integrable
or completely represented by that chart.

A graph at one of the thirteen mass/order sentinels is only a candidate. It
cannot satisfy W2 until an exact arbitrary-positive-mass branch or finite
exhaustive branch partition is proved. Numerical residuals, floating
coefficients, restricted massless models, collision-only curves, and
constant-shape homothetic solutions cannot be promoted.

A complete null result covers exactly four shape covers and exact one- and
two-term Laurent supports with exponents from `-2` through `2`. It says
nothing about larger supports, other algebraic covers, implicit curves not
represented as these graphs, transcendental particular solutions, or
nonexistence of a suitable witness.

The package cannot create or authorize `WP6-DZ-MR-v1`. Only a signed
`QUALIFIED_WITNESS` record naming one frozen full-system witness may do so.
