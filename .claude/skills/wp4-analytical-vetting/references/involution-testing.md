# Involution Testing

Theory and implementation for testing involution (mutual commutativity) of conserved quantities.

## Mathematical Foundation

### Definition of Involution

A set of functions {I₁, I₂, ..., Iₖ} is said to be **in involution** if all pairwise Poisson brackets vanish:

```
{Iᵢ, Iⱼ} = 0  for all i, j ∈ {1, ..., k}
```

### Role in Liouville Integrability

**Liouville's Theorem**: A Hamiltonian system with n degrees of freedom is completely integrable if there exist n functions I₁, ..., Iₙ such that:

1. **Independent**: The gradients ∇I₁, ..., ∇Iₙ are linearly independent almost everywhere
2. **In involution**: {Iᵢ, Iⱼ} = 0 for all pairs
3. **Conserved**: {Iᵢ, H} = 0 for all i

When these conditions hold, the motion is confined to n-dimensional invariant tori.

### Geometric Interpretation

Involution means the Hamiltonian flows generated by each Iᵢ commute:

```
[X_Iᵢ, X_Iⱼ] = X_{Iᵢ,Iⱼ} = 0
```

The integral surfaces foliate phase space into Lagrangian submanifolds.

## Known Integrals of Three-Body Problem

### In Rotating Frame (CR3BP)

The Circular Restricted Three-Body Problem has three known integrals:

```python
def energy(state, mu):
    """
    Energy in rotating frame (not separately conserved in CR3BP,
    but useful for involution testing).
    """
    x, y, z, vx, vy, vz = state
    r1 = np.sqrt((x + mu)**2 + y**2 + z**2)
    r2 = np.sqrt((x - 1 + mu)**2 + y**2 + z**2)
    T = 0.5 * (vx**2 + vy**2 + vz**2)
    U = -(1 - mu)/r1 - mu/r2
    return T + U

def angular_momentum_z(state, mu):
    """
    z-component of angular momentum (rotating frame).
    Note: In rotating frame, this is time-dependent.
    """
    x, y, z, vx, vy, vz = state
    return x*vy - y*vx

def jacobi_constant(state, mu):
    """
    Jacobi constant - THE conserved quantity in CR3BP.
    C = 2Ω - v² where Ω is effective potential.
    """
    x, y, z, vx, vy, vz = state
    r1 = np.sqrt((x + mu)**2 + y**2 + z**2)
    r2 = np.sqrt((x - 1 + mu)**2 + y**2 + z**2)
    Omega = 0.5*(x**2 + y**2) + (1 - mu)/r1 + mu/r2
    v_squared = vx**2 + vy**2 + vz**2
    return 2*Omega - v_squared
```

### In Inertial Frame (General 3BP)

```python
def total_energy_inertial(positions, velocities, masses):
    """Total energy in inertial frame."""
    T = 0.5 * sum(m * np.dot(v, v) for m, v in zip(masses, velocities))
    U = 0
    for i in range(len(masses)):
        for j in range(i+1, len(masses)):
            r_ij = np.linalg.norm(positions[i] - positions[j])
            U -= masses[i] * masses[j] / r_ij
    return T + U

def total_angular_momentum_inertial(positions, velocities, masses):
    """Total angular momentum vector in inertial frame."""
    L = np.zeros(3)
    for r, v, m in zip(positions, velocities, masses):
        L += m * np.cross(r, v)
    return L

def center_of_mass_momentum_inertial(velocities, masses):
    """Total linear momentum (conserved, usually set to 0)."""
    return sum(m * v for m, v in zip(masses, velocities))
```

## Involution Tester Implementation

### Core Class

```python
import numpy as np
from dataclasses import dataclass
from typing import Dict, Callable, List, Optional

@dataclass
class InvolutionResult:
    """Results from involution testing."""
    passed: bool
    poisson_brackets: Dict[str, float]
    max_bracket: float
    tolerance: float
    num_samples: int
    
    def summary(self) -> str:
        lines = ["Involution Test Results:"]
        for name, pb in self.poisson_brackets.items():
            status = "✓" if abs(pb) < self.tolerance else "✗"
            lines.append(f"  {{{name}}} = {pb:.2e}  {status}")
        lines.append(f"  All in involution: {self.passed}")
        return "\n".join(lines)


class InvolutionTester:
    """Test involution between candidate and known integrals."""
    
    def __init__(self, mu: float, tolerance: float = 1e-10):
        self.mu = mu
        self.tolerance = tolerance
        self._known_integrals = {
            'energy': self._energy,
            'angular_momentum': self._angular_momentum_z,
            'jacobi_constant': self._jacobi_constant
        }
    
    def _energy(self, state, mu):
        x, y, z, vx, vy, vz = state
        r1 = np.sqrt((x + mu)**2 + y**2 + z**2)
        r2 = np.sqrt((x - 1 + mu)**2 + y**2 + z**2)
        return 0.5*(vx**2 + vy**2 + vz**2) - (1-mu)/r1 - mu/r2
    
    def _angular_momentum_z(self, state, mu):
        x, y, z, vx, vy, vz = state
        return x*vy - y*vx
    
    def _jacobi_constant(self, state, mu):
        x, y, z, vx, vy, vz = state
        r1 = np.sqrt((x + mu)**2 + y**2 + z**2)
        r2 = np.sqrt((x - 1 + mu)**2 + y**2 + z**2)
        Omega = 0.5*(x**2 + y**2) + (1-mu)/r1 + mu/r2
        return 2*Omega - (vx**2 + vy**2 + vz**2)
    
    def test_involution(
        self,
        candidate: Callable,
        known_integrals: Optional[Dict[str, Callable]] = None,
        num_samples: int = 1000,
        seed: int = 42
    ) -> InvolutionResult:
        """
        Test if candidate is in involution with known integrals.
        
        Parameters:
            candidate: Function I(state, mu) -> float
            known_integrals: Dict of name -> function, or None for defaults
            num_samples: Number of sample points
            seed: Random seed for reproducibility
            
        Returns:
            InvolutionResult with Poisson brackets
        """
        if known_integrals is None:
            known_integrals = self._known_integrals
        
        np.random.seed(seed)
        
        # Compute mean Poisson brackets across samples
        pb_sums = {name: 0.0 for name in known_integrals}
        pb_maxs = {name: 0.0 for name in known_integrals}
        
        for _ in range(num_samples):
            state = self._generate_valid_state()
            
            for name, known_func in known_integrals.items():
                pb = self._compute_poisson_bracket(
                    candidate, known_func, state
                )
                pb_sums[name] += abs(pb)
                pb_maxs[name] = max(pb_maxs[name], abs(pb))
        
        # Average Poisson brackets
        pb_means = {name: pb_sums[name] / num_samples 
                    for name in known_integrals}
        
        # Check if all pass
        all_pass = all(pb_maxs[name] < self.tolerance 
                       for name in known_integrals)
        max_bracket = max(pb_maxs.values())
        
        return InvolutionResult(
            passed=all_pass,
            poisson_brackets=pb_maxs,
            max_bracket=max_bracket,
            tolerance=self.tolerance,
            num_samples=num_samples
        )
    
    def _compute_poisson_bracket(
        self, f_func: Callable, g_func: Callable, 
        state: np.ndarray, epsilon: float = 1e-7
    ) -> float:
        """Compute {f, g} numerically."""
        n = len(state) // 2
        pb = 0.0
        
        for i in range(n):
            q_idx = i
            p_idx = i + n
            
            # Central differences
            state_q_plus = state.copy()
            state_q_minus = state.copy()
            state_q_plus[q_idx] += epsilon
            state_q_minus[q_idx] -= epsilon
            
            state_p_plus = state.copy()
            state_p_minus = state.copy()
            state_p_plus[p_idx] += epsilon
            state_p_minus[p_idx] -= epsilon
            
            df_dq = (f_func(state_q_plus, self.mu) - 
                     f_func(state_q_minus, self.mu)) / (2*epsilon)
            dg_dp = (g_func(state_p_plus, self.mu) - 
                     g_func(state_p_minus, self.mu)) / (2*epsilon)
            df_dp = (f_func(state_p_plus, self.mu) - 
                     f_func(state_p_minus, self.mu)) / (2*epsilon)
            dg_dq = (g_func(state_q_plus, self.mu) - 
                     g_func(state_q_minus, self.mu)) / (2*epsilon)
            
            pb += df_dq * dg_dp - df_dp * dg_dq
        
        return pb
    
    def _generate_valid_state(self) -> np.ndarray:
        """Generate physically valid state."""
        while True:
            x = np.random.uniform(0.5, 1.5)
            y = np.random.uniform(-0.5, 0.5)
            z = np.random.uniform(-0.1, 0.1)
            vx = np.random.uniform(-0.5, 0.5)
            vy = np.random.uniform(0.0, 1.0)
            vz = np.random.uniform(-0.2, 0.2)
            
            state = np.array([x, y, z, vx, vy, vz])
            
            r1 = np.sqrt((x + self.mu)**2 + y**2 + z**2)
            r2 = np.sqrt((x - 1 + self.mu)**2 + y**2 + z**2)
            
            if r1 > 0.1 and r2 > 0.1:
                return state
```

## Pairwise Involution Test

For multiple candidates from WP3, test all pairs:

```python
def test_pairwise_involution(
    candidates: List[Dict[str, Callable]],
    mu: float,
    num_samples: int = 1000,
    tolerance: float = 1e-10,
    seed: int = 42
) -> Dict:
    """
    Test pairwise involution of multiple candidates.
    
    Parameters:
        candidates: List of {'name': str, 'func': Callable}
        
    Returns:
        Dict with involution_matrix, all_commute, failed_pairs
    """
    np.random.seed(seed)
    n = len(candidates)
    
    # Initialize involution matrix
    involution_matrix = np.zeros((n, n))
    
    tester = InvolutionTester(mu=mu, tolerance=tolerance)
    
    # Generate sample states once
    states = [tester._generate_valid_state() for _ in range(num_samples)]
    
    # Test all pairs
    failed_pairs = []
    
    for i in range(n):
        for j in range(i+1, n):
            f_func = candidates[i]['func']
            g_func = candidates[j]['func']
            
            # Average Poisson bracket over samples
            pb_sum = 0.0
            pb_max = 0.0
            
            for state in states:
                pb = tester._compute_poisson_bracket(f_func, g_func, state)
                pb_sum += abs(pb)
                pb_max = max(pb_max, abs(pb))
            
            involution_matrix[i, j] = pb_max
            involution_matrix[j, i] = pb_max
            
            if pb_max >= tolerance:
                failed_pairs.append((
                    candidates[i]['name'],
                    candidates[j]['name'],
                    pb_max
                ))
    
    return {
        'involution_matrix': involution_matrix,
        'all_commute': len(failed_pairs) == 0,
        'failed_pairs': failed_pairs,
        'candidate_names': [c['name'] for c in candidates]
    }
```

## Symbolic Involution Test

When expressions are available, prefer symbolic computation:

```python
import sympy as sp

def test_involution_symbolic(
    I_expr: sp.Expr,
    J_expr: sp.Expr,
    q_vars: List[sp.Symbol],
    p_vars: List[sp.Symbol]
) -> Dict:
    """
    Test involution symbolically.
    
    Returns:
        Dict with bracket (SymPy expr), is_zero (bool), simplified
    """
    n = len(q_vars)
    pb = sp.Integer(0)
    
    for i in range(n):
        q = q_vars[i]
        p = p_vars[i]
        
        dI_dq = sp.diff(I_expr, q)
        dJ_dp = sp.diff(J_expr, p)
        dI_dp = sp.diff(I_expr, p)
        dJ_dq = sp.diff(J_expr, q)
        
        pb += dI_dq * dJ_dp - dI_dp * dJ_dq
    
    # Simplify
    pb_simplified = sp.simplify(sp.trigsimp(sp.radsimp(pb)))
    
    return {
        'bracket': pb,
        'simplified': pb_simplified,
        'is_zero': pb_simplified == 0
    }
```

## Special Cases

### Near-Resonance Behavior

Near resonances, apparent involution may break down:

```python
def test_involution_near_resonance(
    candidate: Callable,
    known_integrals: Dict[str, Callable],
    mu: float,
    resonance_params: Dict,
    num_samples: int = 1000
) -> Dict:
    """
    Test involution specifically near resonance regions.
    
    Resonances can reveal hidden non-commutativity.
    """
    tester = InvolutionTester(mu=mu)
    
    # Generate states near resonance
    states = []
    for _ in range(num_samples):
        state = generate_near_resonance_state(resonance_params, mu)
        states.append(state)
    
    # Test involution on resonant states
    results = {}
    for name, known_func in known_integrals.items():
        pb_values = []
        for state in states:
            pb = tester._compute_poisson_bracket(candidate, known_func, state)
            pb_values.append(abs(pb))
        
        results[name] = {
            'max': np.max(pb_values),
            'mean': np.mean(pb_values),
            'std': np.std(pb_values)
        }
    
    return results
```

### Lifted Space Involution

In S¹-bundle coordinates, test involution of lifted integrals:

def test_involution_lifted(
    I_lifted: Callable,
    J_lifted: Callable,
    mu: float,
    num_samples: int = 1000
) -> InvolutionResult:
    """
    Test involution in lifted (S¹-bundle) space.
    
    Lifted state: [x, y, z, θ, vx, vy, vz, p_θ]
    """
    tester = InvolutionTester(mu=mu)
    
    pb_values = []
    for _ in range(num_samples):
        # Generate lifted state
        base_state = tester._generate_valid_state()
        theta = np.random.uniform(0, 2*np.pi)
        p_theta = np.random.uniform(-1, 1)  # Fiber momentum
        
        lifted_state = np.concatenate([
            base_state[:3], [theta],
            base_state[3:], [p_theta]
        ])
        
        # Compute Poisson bracket in lifted space
        pb = compute_pb_lifted(I_lifted, J_lifted, lifted_state, mu)
        pb_values.append(abs(pb))

    return InvolutionResult(

    )

## Interpretation Guide

### Involution Test Outcomes

| Outcome | Interpretation | Action |
|---------|----------------|--------|
| All {Ĩ, Iⱼ} = 0 | Candidate in involution | Proceed to independence test |
| {Ĩ, C} ≠ 0 | Not commuting with Jacobi constant | May still be valid, different foliation |
| {Ĩ, E} ≠ 0 | Not commuting with energy | Check coordinate system |
| All pairs fail | Fundamentally different structure | May need different framework |

### Non-Involution Does NOT Mean Invalid

A candidate integral can be:
- **Valid** (conserved along trajectories)
- **Independent** (provides new information)
- **Not in involution** (doesn't commute with known integrals)

Such integrals exist in non-Liouville integrable systems (e.g., superintegrability).
