# WP1-RESIDUAL-MAP-v1

This campaign maps every frozen `WP1-CAT-N3BP-v1` candidate to a bounded
follow-on protocol. It ranks numerical evidence quality only. Every row carries
an explicit no-interpretation publication gate.

```bash
./validation-external/wp1-residual-map-v1/run_qualification.sh test
./validation-external/wp1-residual-map-v1/run_qualification.sh freeze
./validation-external/wp1-residual-map-v1/run_qualification.sh execute
./validation-external/wp1-residual-map-v1/run_qualification.sh finalize
./validation-external/wp1-residual-map-v1/run_qualification.sh verify
```
