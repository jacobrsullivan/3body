# WP5-PUB-v1

This campaign qualifies publication packaging, not new three-body science.
Its specification is locked before manuscript and evaluator implementation.

The strongest status available without external human evidence is
`READY_FOR_EXTERNAL_REVIEW`. A language-model review, an internal code review,
or a replay on project-controlled hardware cannot satisfy that external gate.

The authoritative claim and decision rules are in `qualification_spec.json`.
