# WP5-PUB-v1 submission checklist

The evaluator, not this checklist, determines campaign status.

## Internal package

- [ ] Locked specification and all predecessor hashes verify.
- [ ] Manuscript source compiles with no error.
- [ ] Rendered PDF has been visually inspected.
- [ ] Claim ledger and proof dependency map agree with the manuscript.
- [ ] Generic source-disjoint derivation exactly matches the frozen payload.
- [ ] Publication-specific tests and all adversarial controls pass.
- [ ] One-command core replay succeeds from a clean checkout.
- [ ] Canonical artifact manifest verifies.

## Independent review

- [ ] Human review 1 validates against the frozen schema.
- [ ] Human review 2 validates against the frozen schema.
- [ ] Reviewers are distinct, consenting, and independent.
- [ ] Collective expertise covers both required mathematical tracks.
- [ ] No blocker or unresolved major finding remains.
- [ ] Minor/editorial findings have recorded dispositions.
- [ ] An external clean-room receipt and signature validate.

## Author metadata

- [ ] Author name and affiliation status confirmed.
- [ ] Contact and ORCID status confirmed.
- [ ] Contribution statement confirmed.
- [ ] Conflicts statement confirmed.
- [ ] Funding statement confirmed.
- [ ] AI-assistance disclosure confirmed.

## Rights and archives

- [ ] Code license selected.
- [ ] Evidence/data license selected.
- [ ] Manuscript-text license selected.
- [ ] Repository is public or an approved archival alternative is selected.
- [ ] Versioned software archive/DOI prepared.
- [ ] Preprint metadata and complete TeX source bundle checked.
- [ ] Final generated PDF inspected against the qualified PDF.

## Authorization

- [ ] Evaluator reports `READY_FOR_SUBMISSION`.
- [ ] Author explicitly authorizes release.
- [ ] Release commit and artifact-manifest hash recorded.
- [ ] Immutable archive and preprint identifiers recorded after release.

Until every required item is satisfied, the package must not be described as
submission-ready or published.
