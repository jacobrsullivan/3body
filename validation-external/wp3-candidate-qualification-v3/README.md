# WP3 Candidate Qualification v3

This gate consumes the immutable `WP3-UP-CAND-v3` search chain. A verified
spectral null must leave the publication reserve sealed, create no
candidate-specific lock, and prohibit candidate interpretation. An unresolved
training-eligible subspace would instead require a new development/calibration
resolution specification before any sealed execution.

Run:

```bash
./validation-external/wp3-candidate-qualification-v3/run_gate.sh
```
