# WP1-RESIDUAL-MAP-v1 Qualification Boundary

This component assigns each frozen `WP1-CAT-N3BP-v1` row to a bounded
follow-on research protocol and ranks numerical evidence quality within that
protocol.

It does not discover or interpret an invariant. Stable labels authorize only
a candidate-specific normal-form/KAM qualification proposal; unstable labels
authorize only a candidate-specific manifold/scattering qualification
proposal. Exact first-NVE exceptional masses receive an overlay, not an
integrability claim. Every later interpretation requires a new locked and
sealed qualification.
