14 dimensionless canonical upstairs variables, evaluates exact Lie
derivatives, removes value identities and the represented known algebra, and
tests the remaining modes on disjoint calibration data and multiple gauges.

campaign cannot execute it.  A surviving mode can only trigger a new
candidate-specific qualification lock.
