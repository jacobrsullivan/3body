# WP2-3BFLOWQ-v1

This qualification independently replicates Jacobi reduction conventions and
tests the production canonical, generic SO(3)-quotient, reconstruction, and
constrained pairwise KS physical-time vector fields on qualified external
spatial checkpoints. It depends on the already qualified Kepler/KS prototype
and the separate spatial N3BP qualification.

The pairwise KS object is a redundant constrained lift of one Newtonian flow.
No pair-specific or global Sundman time, decoupled oscillator, collision
regularization, or three-body integrability claim is made.
